# MapGen -- Dynamická generace hexagonové mapy

Tento Python prográmek vznikl v rámci předmětu Programování 2 v prvním ročníku bakalářského studia na MFF UK. Cílem bylo dynamicky vytvářet šestiúhelníkovou mapu s rozumně realistickým chováním terénu (hladkost reliéfu, tok řek z větší nadmořské výšky do moře).

Vyčerpávající popis tohoto projektu naleznete v docs.pdf.
